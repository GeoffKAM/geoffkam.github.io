Econ 4850 Course Materials

Lecture notes and problem sets from Econ 4850: Economic Analysis with Python (Spring 2025), as Jupyter notebooks. The lecture notes were run end to end, so every output comes from the code shown; the problem sets contain the questions only.

Each link downloads a notebook. Open it in JupyterLab or VS Code, or upload it to Google Colab. To run everything, install Anaconda (Python 3.11 or later) and pip install autograd fredapi plotly.
