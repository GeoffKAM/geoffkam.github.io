# Econ 4850 · Economic Analysis with Python

Geoffrey Kam, Washington University in St. Louis (Spring 2025).

Lecture notes and homework as Jupyter notebooks. The lecture notes were run
end to end before posting, so every output you see comes from the code shown.
Homework notebooks contain the problems only.

## Setup

Install [Anaconda](https://www.anaconda.com/download) (Python 3.11 or later), then
`pip install autograd fredapi plotly`. Lecture 5 needs a free
[FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html), stored in the
environment variable `FRED_API_KEY`.
